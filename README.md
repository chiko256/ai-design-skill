# AIデザインSkill

AIデザインSkillのCodex接続用リポジトリです。

TOP・LP、下層ページ、SPデザイン、編集可能なFigmaデータの制作をCodexから進められます。

## 初回設定

Codexで新しいタスクを開き、このリポジトリのURLと一緒に次の文章を送ってください。

> このGitHubリポジトリの `SETUP_WITH_AI.md` を読み、AIデザインSkillとFigmaの初回設定をしてください。私の操作が必要なところでは、何をすればよいか教えてください。

設定には、管理者から個別に届く契約者専用トークンが必要です。トークンはGitHub、Codexのチャット、Notion、Figma、案件ファイルへ貼らないでください。

## アップデート

AIデザインSkillは、制作を始めるたびにGitHubの最新版を確認します。更新がある場合は自動で反映されるため、利用者による更新操作は不要です。

GitHubから取得するのは、接続用Skill・設定例・実行ファイルです。詳しい制作工程と専門ノウハウは、契約者認証付きの非公開サーバーから実行時に必要な範囲だけ取得します。

## 利用開始

設定後は、Codexへ次のように送ります。

> AIデザインで、〇〇のTOPページを作りたいです。

## ご利用条件

AIデザインSkillの利用には、有効な契約者専用トークンが必要です。このリポジトリを公開していても、契約者専用機能はトークンなしでは利用できません。
